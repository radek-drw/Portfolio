Car Performance Tuning Website

This website was built for a client specialising in engine tuning and performance upgrades. Originally built with WordPress, it was later recreated using React and Tailwind CSS to provide greater flexibility in design and development.

Key features include:

  • AWS infrastructure managed with Terraform (Infrastructure as Code)
  • Automated CI/CD pipeline using GitHub Actions
  • Admin panel with CRUD functionality to manage company listings
  • Contact form with file uploads for businesses interested in advertising on the website
  • Serverless backend using AWS Lambda, API Gateway, DynamoDB, S3 and SES to process submissions, manage company data and store uploaded files
  • Interactive map displaying company locations, with markers and popups containing company details and photos
  • Frontend and backend validation, including file type and size restrictions
  • WebP image optimisation to improve page loading performance
  • Accessibility improvements using ARIA attributes
  • Animated image slider with synchronised text animations

Global Weather App (React)

I built Global Weather App using React to let users check the weather anywhere in the world. It uses Google Maps API to help find the right location, with city suggestions and extra details to avoid confusion between places with the same name. The app shows current weather conditions, hourly forecasts and a five-day forecast. Users can switch between Celsius and Fahrenheit, choose from seven interface languages, and change between light and dark themes. There's also an option to check the weather at your current location, along with images that change depending on the sky conditions.
